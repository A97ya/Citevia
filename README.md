# Citevia

Citevia 是面向论文写作的 Windows 桌面参考文献管理工具，支持文献检索与信息核对、项目文献库、自定义参考文献格式，以及 Microsoft Word 引用插入与管理。

## 下载与安装

[下载 Citevia 最新正式版](https://github.com/A97ya/Citevia/releases/latest)

- Windows 安装包：在最新发布页下载 `ReferenceStudio-Setup-4.1.exe`。
- 升级前保存并关闭 Word，退出 Citevia，再运行安装包覆盖升级，无须先卸载。
- 也可以在已安装软件的“设置 → 检查更新”中获取维护版本。
- 安装包未进行商业代码签名，请核对下载来源和发布页提供的 SHA-256。

## 主要功能

- 按 DOI 或论文标题批量导入，查看不同来源的文献信息与差异。
- 按论文项目管理文献库，保留文献、格式与项目设置。
- 自定义参考文献样例、作者规则、字体与段落排版，并复用期刊格式模板。
- 在 Microsoft Word 中插入和管理引用，支持重复引用编号复用、编号更新与分区参考文献。

多来源信息一致不等于绝对无误。正式投稿前，请核对原文与目标期刊要求；操作重要文稿前，请自行保留副本。

## 更新渠道与兼容性

正式项目和后续发布统一使用 [A97ya/Citevia](https://github.com/A97ya/Citevia)。旧仓库地址仅保留为旧版兼容更新通道；升级后使用新渠道。历史版本请从本仓库的 [Releases](https://github.com/A97ya/Citevia/releases) 查看。

为保持覆盖升级与现有文献库兼容，安装包文件名及部分内部标识保留 `ReferenceStudio`。产品名称和对外展示统一为 **Citevia**。
